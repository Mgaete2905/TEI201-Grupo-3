# Gráficos – Testing del sistema de alertas

Esta carpeta contiene los gráficos obtenidos durante la evaluación experimental del sistema de alertas del prototipo IoT de monitoreo de turbidez.

Se realizaron cinco ciclos de medición utilizando agua limpia y soluciones de caolín de 185 y 345 mg/L, con el objetivo de verificar el comportamiento del sensor y la activación de alertas al superar el umbral de **133,4 NTU**.

Los gráficos permiten visualizar la evolución de la turbidez estimada, su comparación con el umbral y las diferencias entre las muestras evaluadas. Los promedios por muestra son aproximados debido a los cambios manuales entre recipientes.
