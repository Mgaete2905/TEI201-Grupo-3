# Renders y Visualizaciones 3D – Nodo Flotante IoT

## 1. Descripción general

Esta carpeta contiene las visualizaciones tridimensionales del nodo flotante diseñado para el prototipo IoT de monitoreo de turbidez, desarrollado en el marco del Avance #3 de la asignatura TEI201 – Taller de Diseño en Ingeniería.

Las imágenes fueron obtenidas a partir del modelo tridimensional desarrollado en Autodesk Fusion 360 y permiten representar el diseño exterior del encapsulado, la distribución de los componentes electrónicos y la organización del conjunto mediante una vista explosionada.

Estas visualizaciones complementan los archivos editables de Fusion 360, los planos técnicos y las fotografías del prototipo construido.

## 2. Archivos disponibles

### `01_exterior.png` – Ensamble cerrado

Representación isométrica del nodo con el encapsulado completamente cerrado.

Permite observar la geometría exterior de la caja, la disposición de la tapa y la configuración general del sistema de protección.

Esta vista se utiliza para presentar el aspecto exterior del dispositivo y su configuración ensamblada.

### `02_interior.png` – Vista interior sin tapa

Representación tridimensional del encapsulado abierto, que permite observar la organización interna de los componentes.

Se identifica la bandeja portacomponentes, la ubicación de la batería externa, el espacio destinado al circuito electrónico y la integración del sensor de turbidez en la estructura.

Esta vista permite comprender la distribución espacial de los elementos y la accesibilidad para tareas de montaje y mantenimiento.

### `03_vista_explosionada.png` – Vista explosionada del conjunto

Representación del nodo flotante con sus componentes separados verticalmente para facilitar la identificación de las piezas y comprender su secuencia de ensamblaje.

La imagen identifica los siguientes elementos:

| N.º | Componente |
|---|---|
| 01 | Caja base |
| 02 | Tapa |
| 03 | Bandeja portacomponentes |
| 04 | Separadores |
| 05 | Tuercas |
| 06 | Sensor de turbidez |
| 07 | Power bank |
| 08 | Protoboard |
| 09 | ESP8266 NodeMCU |
| 10 | Placa acondicionadora del sensor |
| 11 | Velcro de fijación |

Esta visualización permite comprender la relación entre el encapsulado, los elementos de fijación, la bandeja y los componentes electrónicos.

## 3. Objetivos de las visualizaciones

Los renders y vistas tridimensionales cumplen las siguientes funciones:

- **Presentación del diseño:** mostrar la configuración exterior del encapsulado.
- **Distribución de componentes:** representar la ubicación de los elementos electrónicos dentro de la caja.
- **Comprensión del ensamblaje:** identificar las piezas que conforman el conjunto y su disposición.
- **Documentación técnica:** complementar los planos de fabricación y el modelo 3D editable.
- **Comparación con el prototipo físico:** facilitar la revisión de las diferencias entre el diseño digital y el montaje construido.

## 4. Características de las imágenes

| Característica | Descripción |
|---|---|
| Software de diseño | Autodesk Fusion 360 |
| Formato de exportación | PNG |
| Tipo de representación | Visualización CAD tridimensional con sombreado |
| Vistas disponibles | Exterior, interior y explosionada |
| Identificación de piezas | Incluida en la vista explosionada |
| Aplicación | Documentación del diseño mecánico y presentación del prototipo |

Las imágenes priorizan la claridad geométrica y la identificación de componentes. No corresponden necesariamente a renderizados fotorrealistas con materiales e iluminación físicamente simulados.

## 5. Relación con el prototipo construido

El modelo tridimensional sirvió como referencia para la integración de los componentes electrónicos en el encapsulado físico.

El montaje construido incorpora una caja de protección, una bandeja interior fabricada mediante impresión 3D, el sensor de turbidez, el ESP8266 NodeMCU y una batería externa.

Adicionalmente, el proyecto contempla elementos de flotación destinados a mantener el sistema sobre la superficie del agua. Estos elementos no aparecen representados en las tres visualizaciones disponibles.

Las fotografías del montaje físico se encuentran documentadas en la carpeta de hardware correspondiente.
