# Prototipo Alpha – Versión Inicial

Esta carpeta contiene la documentación correspondiente a la versión inicial del prototipo desarrollado para el sistema de monitoreo de turbidez del agua.

Aquí se encuentran los archivos asociados a las primeras etapas de diseño y desarrollo, incluyendo planos, esquemas electrónicos, diseño preliminar de la PCB y otros documentos técnicos utilizados durante la construcción del prototipo.

El propósito de esta sección es registrar el desarrollo inicial del proyecto, permitiendo visualizar su evolución y las modificaciones realizadas en versiones posteriores.
